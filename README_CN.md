# 🦞 NovelClaw: 自进化 AI 网文写作插件 (基于 OpenClaw)

> **NovelClaw** 是一款专为 **OpenClaw (小龙虾)** 生态设计的专业级 AI 写作插件。它能将你的小龙虾 Agent 转化为一位“网文大神”，具备长篇叙事、场景化文风自动适配以及通过反馈循环实现自我进化的能力。

[English Documentation](./README.md)

---

## 🌟 核心亮点

### 1. 小龙虾原生集成
作为标准 Skill 深度集成。通过“新建小说”、“写新章节”等自然语言指令即可轻松触发，无需复杂配置。

### 2. 场景化文风引擎
自动识别并加载不同叙事场景的专用文风补丁：
- ⚔️ **打斗场景**: 短句、快节奏、高动词密度，增强画面感。
- ❤️ **情感场景**: 微表情捕捉、环境烘托、细腻心理描写。
- 🔍 **悬疑场景**: 视角限制、留白、营造心理压迫感。

### 3. 自我进化循环
自动检测“AI 味”表达（如“不仅如此”、“总之”等），并更新本地避雷词库。它会根据你的修改建议不断学习，使生成的文风越来越接近你的个人风格。

### 4. 长效一致性 (RAG)
严密管理世界观与人物志，确保百万字连载不“吃书”，保持人物性格与背景设定的一致性。

## 🚀 快速开始

### 1. 环境准备
- **Node.js**: v24+ (用于运行 OpenClaw / 小龙虾)
- **Python**: v3.10+ (用于运行核心引擎)
- **OpenClaw**: 请确保已安装并启动 [OpenClaw](https://github.com/openclaw/openclaw)。

### 2. 安装步骤
#### 方式一：快速安装（推荐）
1. 从本仓库下载 `novelclaw.skill` 文件。
2. 将其放入你的小龙虾插件目录：`~/.openclaw/skills/`。
3. 重启你的 OpenClaw Gateway。

#### 方式二：手动安装
1. 克隆本仓库。
2. 将 `src/` 目录下的所有内容复制到 `~/.openclaw/skills/novelclaw/`。
3. 确保已安装 `requirements.txt` 中的依赖项。

### 3. 使用方法
安装完成后，直接对你的小龙虾 Agent 下令：
- “新建小说《剑破苍穹》，类型玄幻”
- “写第一章”
- “写一段主角和反派对决的打斗场景”
- “检查一下上一章有没有 AI 味”
