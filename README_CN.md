# 🦞 NovelClaw — 自进化 AI 网文写作助手

NovelClaw 是一个基于 OpenClaw 的长篇小说写作 Skill。它不是"帮你写小说的AI"，而是一个**会学习你风格、会自我纠错、会按场景切换文风**的写作搭档。

---

## 核心功能

### 1. 场景化文风引擎

写打斗时自动切换短句快节奏，写情感时切换微表情+环境烘托。四种文风随场景自动匹配：

| 场景 | 触发词 | 文风特点 |
|------|--------|----------|
| ⚔️ 打斗 | 战斗、交手、出剑 | 短句为王、动词密度+30%、感官轰炸 |
| ❤️ 情感 | 对话、独处、分别 | 微表情、环境烘托、留白 |
| 🔍 悬疑 | 探索、发现、暗处 | 视角限制、心理压迫、不说破 |
| 📖 通用 | 默认 | 简洁、画面感、信息密度高 |

### 2. 自进化避雷系统

写完每一章后自动扫描，发现AI味词汇和套路表达：

```
📝 自检报告: 002.md
==================================================
🚫 避雷词 (1 个):
   [总之] 出现 1 次 → 自动修正为[说到底]

📏 字数: 1653 中文字
==================================================
```

- 自动扫描 20+ 个内置避雷词
- 检测AI味句式模式（情绪标签化、万能比喻、无效对话等）
- 发现新避雷词自动追加到词库，越写越严格
- 高频词警告（"突然"出现超过3次就提醒）

### 3. 大纲驱动写作

不是写到哪算哪，而是先定大纲再动笔：

```
第一步：定世界观和人物
第二步：列 5-10 章大纲
第三步：确认后才开始写
```

每章写完自动记录摘要，确保剧情连贯、不"吃书"。

### 4. 分段写作 + 人工反馈

不一口气写完让你看大段文字，而是分段暂停：

```
写 500 字开头 → "方向对吗？继续？"
写到 1500 字 → "节奏和文风 ok 吗？"
写完全章 → 自检 + 字数确认
```

你说"直接写完"就跳过中断，一口气出。

### 5. 续写无缝衔接

写下一章时自动读取上一章末尾和剧情摘要，从新的场景或时间点切入，不重复、不断档。

### 6. 人物一致性管理

写对话前自动检查人物性格设定。不会让沉默寡言的角色突然话痨，不会让火辣性格的角色突然温柔。

## 快速开始

### 安装

```bash
# 解压到 Skills 目录
tar -xzf novelclaw-v2.skill -C ~/.openclaw/skills/

# 重启 OpenClaw
openclaw gateway restart
```

### 新建小说

对 Agent 说：

> "新建小说《剑起青萍》，类型玄幻，设定是剑修世界但主角无法握剑，主角叫林风……"

Agent 会：
1. 初始化项目目录
2. 写入世界观和人物
3. 引导你定大纲
4. 确认后开始写第一章

### 写章节

> "写第一章"
> "写一段打斗场景"
> "继续写下一章"

### 人物管理

> "加个人物：苏瑶，天剑宗天才，性格火辣"
> "苏瑶的性格改成外冷内热"
> "查一下林风的人物设定"

## 项目结构

```
novel/                          # 你的小说项目（自动创建）
├── config.json                 # 项目配置（标题、类型、字数目标）
├── characters.json             # 人物志（性格、关系、战斗风格）

├── chapters/                   # 已写章节
│   ├── 001.md
│   └── 002.md

    ├── outline.md              # 总大纲
```

## 自检脚本用法

手动运行自检（通常由 Agent 自动调用）：

```bash
# 检查章节
python3 ~/.openclaw/skills/novelclaw/scripts/self_check.py \
  novel/chapters/001.md \
  novel/style_constraints.json

# 只检查不修正
python3 ~/.openclaw/skills/novelclaw/scripts/self_check.py \
  novel/chapters/001.md \
  novel/style_constraints.json --no-fix
```

自检内容：
- ✅ 避雷词扫描（20+ 内置词 + 用户自定义词）
- ✅ AI味句式检测（情绪标签化、万能比喻、无效对话等）
- ✅ 高频词警告（"突然"、"忽然"等出现过多）
- ✅ 字数统计（中文字符数）
- ✅ 自动修正 + 自动追加新避雷词到词库

## 避雷词库

初始词库包含 20+ 个高频AI味词汇：

```
不仅如此、总之、仿佛在说、显然、毫无疑问、
值得一提的是、不言而喻、众所周知、事实上、
与此同时、换言之、可以说、某种程度上、
综上所述、简而言之、令人印象深刻、令人叹为观止……
```

每写一章，自检脚本会自动扫描。发现新的避雷词会追加到 `style_constraints.json`，词库随使用不断增长。

## 配置说明

### config.json

```json
{
  "title": "剑起青萍",
  "genre": "玄幻",
  "default_scene": "general",
  "word_count_target": 2500,
  "created_at": "2026-05-02T16:00:00"
}
```

- `word_count_target`：每章目标字数，默认 2500。可在初始化时通过 `--word-count` 修改。

### style_constraints.json

```json
{
  "banned_phrases": ["不仅如此", "总之", ...],
  "preferred_style": {
    "sentence_length": "短句为主，长短交替",
    "description_density": "高动词密度，少形容词堆砌",
    "dialogue_style": "简洁有力，符合人物性格"
  },
  "evolution_log": [
    {"date": "2026-05-02", "action": "自检发现 1 个新避雷词", "words": ["某个词"]}
  ]
}
```

## 已知限制

- 依赖 OpenClaw 自身的 LLM 能力，写作质量取决于底层模型
- 文风切换是"指导"而非"强制"，极端情况下 LLM 可能忽略规则
- 暂不支持多人协作写作
- 暂不支持自动插图
